## 📖 Overview

**NavBarPets** is a modern desktop companion application that roams freely on top of your Windows Taskbar, puts on headphones and grooves along with songs playing on your PC, observes a real-time circadian sleep schedule, supports a **5-Skin Morphological System** (Mythic, Classic, Pixel Art, Sakura, Evori Dreamwings) across **13 unique species**, reacts to petting and drag-and-drop interactions, and features over 75 procedural kinematic animations.

Powered by a transparent overlay engine and hardware-accelerated HTML5 Canvas rendering, it operates quietly in the background with minimal system overhead (low CPU & RAM consumption).

## 🛠️ Building from Source & Development

### Prerequisites:
- **Node.js** (v18 or higher recommended)
- **npm** or **yarn**
- **Windows 10 / 11**

### 1. Clone the Repository and Install Dependencies:
```bash
git clone https://github.com/phaticusthiccy/NavBarPets.git
cd NavBarPets
npm install
```

### 2. Launch in Development Mode:
```bash
npm start
```

### 3. Build Windows Executables (`.exe`):
```bash
npm run dist
```
Installer (`NavBarPets Setup x.x.x.exe`) and portable (`NavBarPets x.x.x.exe`) packages will be output to the `dist/` directory.
